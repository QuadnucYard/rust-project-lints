# rust-project-lints

Lint and style tools for Rust projects.

- **cargo-stylecheck** ([crates/stylecheck](crates/stylecheck/README.md)) — layout style checker for Rust sources and Cargo/TOML manifests.
- **cargo-depform** ([crates/depform](crates/depform/README.md)) — dependency graph architecture checker for Cargo workspaces.

Nothing is published to crates.io for now; run each tool from the workspace with `cargo run -p <package>`.
